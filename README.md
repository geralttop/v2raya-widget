# v2rayA в баре Noctalia

Плагин для Noctalia 5.4.1 (API 42) и локального v2rayA 2.5.13 по адресу `http://127.0.0.1:2017`.

- ЛКМ по VPN открывает панель: состояние, переключатель и выбор сервера.
- ПКМ включает/выключает VPN, если состояние известно.
- Подсказка показывает текущий сервер; обновление каждые 5 секунд.
- Первый вход — логин и пароль существующего аккаунта v2rayA в панели. Пароль не записывается; токен хранится в `~/.local/state/noctalia/plugins/data/geralttop/v2raya/token` (0600, каталог 0700). При истечении токена панель снова предлагает вход.

Выбор сервера атомарно заменяет состав группы `proxy` одним сервером; другие группы не меняются. При выключенном VPN выбор не запускает его. Настройки маршрутизации сохраняются. Прежде настроенная балансировка группы proxy заменяется одиночным сервером. Текущий выбранный участник учитывается по флагу `selected`.

## Установка

```sh
ln -s /home/geralttop/my_folder/projects/2026/v2raya-widget ~/.local/share/noctalia/plugins/v2raya
noctalia msg config-reload
noctalia msg plugins enable geralttop/v2raya
noctalia msg config-set widget.vpn.type '"geralttop/v2raya:bar"'
```

Добавить `vpn` в `bar.default.end`, сохранив остальные виджеты. На этом компьютере уже установлен перед `network`.

## Проверки

```sh
noctalia plugins lint .
lua tests/service.lua .
```

Тесты: нормализация подписок с индексами от нуля, чтение состояния, остановка, атомарный выбор сервера, устаревший список, отсутствие/истечение токена. Проверены загрузка плагина работающей Noctalia, отображение панели и реальный авторизованный GET состояния. Переключение реального VPN и смена сервера автоматически не выполнялись, чтобы не прервать текущую сеть.

## Отключение

Убрать `vpn` из `bar.default.end`, затем `noctalia msg plugins disable geralttop/v2raya`. Токен можно удалить отдельно для выхода. Исходники и остальные настройки не удаляются.

API сверены с исходниками v2rayA v2.5.13 и Noctalia v5.4.1. `sub` в NodeRef индексируется с нуля, хотя список подписок содержит `id` от единицы.
